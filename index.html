Willis Vault Backup

A privately operated utility for backing up selected local files to the owner's Google Drive and restoring them when needed.

The utility uses Restic for encrypted, versioned backups and Rclone for Google Drive transport. Google authorization connects the owner's storage account; this website does not collect credentials or receive backup files.

This is a personal-use integration, not a public signup service. Backup and restore operations run on the owner's computers.
